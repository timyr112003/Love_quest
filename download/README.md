# Наша История ❤️ — Романтический квест

Веб-сайт-квест для дня рождения 18.09.2026.
Курсирует по **6 точкам Москвы**: Большой театр → Красная площадь → Зарядье → Александровский сад → Арбат → Патриаршие пруды.

## 🚀 Запуск

### Установка зависимостей
```bash
npm install
# или
bun install
# или
yarn install
```

### Запуск dev-сервера
```bash
npm run dev
```

Откройте http://localhost:3000 в браузере.

### Сборка для продакшна
```bash
npm run build
npm start
```

## ⚙️ Настройка квеста

Все пароли и тексты загадок находятся в одном файле:

```
src/lib/quest-config.ts
```

### Что нужно настроить перед запуском:

1. **`candyPassword`** (этап Зарядье) — слово, которое вы положите внутрь секретной жвашки.
   По умолчанию: `"сердце"`

2. **`paperLines`** (этап Александровский сад) — 5 строк на бумажке.
   По умолчанию первые буквы складываются в **АРБАТ**.
   ⚠️ Если поменяете строки — проверьте, чтобы акростих остался осмысленным, и обновите `paperAccepted`.

3. **`finalRiddleText`** + **`finalPassword`** (этап Патриаршие пруды) — загадка в конверте и ответ на неё.
   По умолчанию ведёт к ужину, ответ: `"вечер"`.
   Замените под ваш финальный сценарий!

4. **`finaleText`** — финальное поздравление на экране после прохождения всего квеста.

### Другие параметры:
- `daysAccepted` — ответ на загадку про количество дней (759)
- `bolshoiAccepted`, `redSquareAccepted`, `arbatAccepted`, `patriarchAccepted` и т.д. — списки допустимых вариантов ответов для каждой локации

## 🎭 Этапы квеста (16 этапов, 6 точек)

1. **Intro** — обложка с началом истории
2. **Пароль №1** — 759 дней (20.08.2024 → 18.09.2026)
3. **Локация №1** — Большой театр (загадка про колесницу с 4 лошадьми)
4. **На месте** — 8 колонн фасада
5. **Локация №2** — Красная площадь (загадка про стены, купола, ряды)
6. **На месте** — Минин (памятник Минину и Пожарскому)
7. **Локация №3** — Зарядье (загадка про парк и парящий мост)
8. **На месте** — секретная жвашка (физический предмет)
9. **Локация №4** — Александровский сад (загадка про Вечный огонь)
10. **На месте** — бумажка с акростихом **АРБАТ** (первые буквы 5 строк)
11. **Локация №5** — Арбат (загадка про улицу музыки и искусства)
12. **На месте** — **подарок без пароля** (просто так, потому что день рождения)
13. **Локация №6** — Патриаршие пруды (загадка про Булгакова)
14. **На месте** — **потребовать подарок** (кнопка 🎁 Потребовать подарок)
15. **Конверт** — финальная загадка в конверте
16. **Финал** — поздравление

## 🎨 Дизайн

- Шрифты: Playfair Display + Cormorant Garamond (с поддержкой кириллицы)
- Палитра: тёплый кремовый фон, винно-красные акценты, золото
- Анимации: падающие сердца, плавные переходы между этапами
- Адаптивная вёрстка для мобильных и десктопа
- Прогресс-индикатор с 6 точками (одна на каждую локацию)

## ✨ Особенности

- **Кнопка «Далее →»** после правильного ответа — пользователь сам решает, когда переходить дальше (нет авто-перехода)
- **Flow «Я на месте»**: на каждой локации — кнопка «📍 Я на месте» → подтверждение «Ты точно на месте?» → **запрос совместного фото с 5-минутным таймером** → продолжение
- **Таймер на фото** ⏱ — обратный отсчёт 5 минут, пульсирует красным на последней минуте. Не блокирует кнопку — если время вышло, можно просто сделать ещё кадр
- **Сохранение прогресса** в localStorage — можно закрыть и вернуться
- **Проверка паролей** без учёта регистра, пробелов и пунктуации
- **Множественные варианты ответов** — например, «Большой театр», «большой», «bolshoi»
- **Акростих на бумажке** — буквы В-М-Е-С-Т-Е подсвечены, чтобы намекнуть на принцип
- **Прогресс-индикатор** сверху показывает, на какой из 6 точек вы находитесь
